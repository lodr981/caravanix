# Pro Radka

Píše mistr, nejvýš jednou denně, nejvýš 5 položek. Radek odpovídá krátce (ano / ne / jinak: …). Bez odpovědi se pokračuje jinou prací. U položek, které nejsou bezpečnostní, platí po 48 hodinách výchozí volba.
