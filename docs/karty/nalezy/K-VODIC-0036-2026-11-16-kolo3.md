## Poznámky (verdikt nemění)

- „nad 199,9 A“ v tvrzení je zaokrouhlení. Přesná mez je 199,889 A, takže proudy 199,89–199,90 A hlášku také spustí. Rozdíl je 0,011 A a kalkulačka se při něm chová opatrněji, než text říká. Pro přesnost doporučuji „nad 199,88 A“ nebo „asi od 200 A“.
- Text kalkulačky („patří k němu pojistka Class T“) je kategoričtější než karta („typicky Class T“). Victron připouští i jiné pojistky s dostatečnou vypínací schopností („Alternative fuses … with adequate interrupt rating“). Pro web je přesnější formulace karty.
