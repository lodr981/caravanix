# Nález K-VODIC-0035, kolo 2 (2026-11-16)

**Verdikt: SEDÍ**

## Co jsem ověřil

- **Prysmian, Single-core cables**: třída A 85 °C (T1) převážně PVC, dveře a víka; třída B 105 °C (T2) obvykle PVC; třída C 125 °C/3 000 h teplu odolné (zesítěný PE, 42X, PP, případně speciální PVC), „main application … engine compartment at moderate temperature range up to 125°C“; třída D 150 °C/3 000 h „designed for applications in engine compartments“. Sedí.
- **Caledonian FLR2X11Y 2×0,5**: Applications „ABS braking systems, wiring inside the engine compartment“; ISO 6722 Class C; −40 až +125 °C. Sedí.
- **Caledonian FLR2X-A 1×1,5**: obvody motoru a kostry baterie s vysokou teplotou, trvale −40 až 125 °C; Class C; XLPE. Sedí.
- **Bod 6 (kalkulačka v2)**: `docs/KALKULACKA_PRUREZU.md`, Výpočet bod 10: `MOTOR_VYSSI_TRIDA` při uložení `motor` („použijte kabel pro vyšší teplotu, třída C 125 °C nebo D 150 °C“). Tvrzení karty odpovídá; dodatek „ne běžný PVC kabel do 105 °C“ podporuje Prysmian (PVC je typicky třída A/B, motorový prostor třída C/D).
- **Úvaha „na bezpečné straně“**: k = 0,5 je Lapp Table 12-2 pro vodič 70 °C při okolí 60 °C; pro teplu odolné kabely Lapp Table 12-4 dává do 50 °C 1,00 a 135 °C kabel ještě 1,00 i výš. Kabel 125 °C tedy při okolí do 60 °C ztrácí méně než 0,5. Sedí (s mezí okolí 60 °C, kterou uvádí K-VODIC-0004).
- **Rozhodnutí**: hláška je v kapitole Verze 2, kterou Radek rozhodl 16. 11. 2026 (`docs/ROZHODNUTI.md`). Karta netvrdí víc.
